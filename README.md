# Posted

'Posted' is a responsive blog platform that users can post and comment .

## Features
- Users can register and login
- Users can create, read, update and delete posts
- Users can comment on posts

## Tech Stacks
-Frontend : React, Vite, Tailwind CSS, Tanstack Query, 
-Backend : Nodejs, Express, Typescript, Postgresql, Prisma ORM

## Prerequisites
- Node.js 20+
- The [My Blog Api](https://github.com/Paung1999/my-blog-api.git) running locally

### Installation
git clone https://github.com/Paung1999/posted.git
cd posted
npm install
npm run dev

## Related Repository
The backend for this frontend is [my-blog-api](https://github.com/Paung1999/my-blog-api.git)
